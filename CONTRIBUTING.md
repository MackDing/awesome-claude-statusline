# Contribution Guidelines

Thank you for your interest in contributing to Awesome Claude Statusline!

## Adding a Project

1. **Fork** this repo and create a branch
2. Add the project to the **appropriate category** in `README.md`
3. Use the table format: `| [owner/repo](url) | ⭐ N | Short description |`
4. Keep descriptions **concise** (under 100 characters if possible)
5. Projects should be **open source** and hosted on GitHub
6. Projects must be **specifically related** to Claude Code statusline/status bar customization
7. Sort within each category by **stars descending**

## Categories

- **Featured**: 100+ stars
- **Full-Featured**: Multiple data segments (context, cost, rate limits, git, etc.)
- **Minimal / Lightweight**: Single file or zero dependencies
- **Powerline / Themed**: Focus on visual aesthetics
- **Language-Specific**: Non-JS/bash implementations (Go, Rust, Python, etc.)
- **Integrations & Dashboards**: tmux, Zellij, Discord, monitoring dashboards
- **Fun & Creative**: Pets, avatars, unique approaches

## Quality Standards

- The project should have a README with installation instructions
- The project should actually work (not just a fork with no changes)
- Personal dotfile repos with no documentation may be declined

## Updating Star Counts

Star counts are snapshots. Don't worry about keeping them perfectly up-to-date — we do periodic refreshes.

## Pull Request Process

1. Ensure your addition follows the format above
2. Check that the project isn't already listed
3. One project per PR is fine; batches are also welcome
4. PR title: `Add owner/repo-name`
